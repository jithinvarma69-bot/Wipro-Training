Assignment 4: Distribution Analysis (Seaborn) The Dataset: Use the built-in 'tips' dataset tips = sns.load_dataset('tips') The Question: 1. Create a Histogram (using `displot`) for the `total_bill` column. Include a KDE (Kernel Density Estimate) line and change the color to "darkblue". 2. Generate a JointPlot to compare `total_bill` (x-axis) and `tip` (y-axis). Add a regression line to see the correlation. 3. Create a BoxPlot comparing the `total_bill` across different `days` of the week, colored (hue) by whether the customer was a `smoker`. 


Code:

import seaborn as sns
import matplotlib.pyplot as plt

# Load dataset
tips = sns.load_dataset('tips')

# 1. Histogram with KDE
sns.displot(tips['total_bill'], kde=True, color='darkblue')
plt.title("Histogram of Total Bill with KDE")
plt.show()

# 2. JointPlot with regression
sns.jointplot(x='total_bill', y='tip', data=tips, kind='reg', color='green')
plt.show()

# 3. BoxPlot by day and smoker status
sns.boxplot(x='day', y='total_bill', hue='smoker', data=tips, palette='Set2')
plt.title("Total Bill by Day and Smoker Status")
plt.show()


output:

Output Summary for Seaborn Plots:

1. **Histogram with KDE (Total Bill)**
   - A histogram of the `total_bill` values, overlaid with a smooth Kernel Density Estimate line in dark blue.
   - Shows distribution peaks around $10–20 and a tail extending toward higher bills.

2. **JointPlot (Total Bill vs Tip)**
   - Scatter plot of `total_bill` (x-axis) vs `tip` (y-axis).
   - Regression line added to visualize positive correlation: higher bills generally lead to higher tips.

3. **BoxPlot (Total Bill by Day, colored by Smoker)**
   - X-axis: Day of the week (`Thur`, `Fri`, `Sat`, `Sun`).
   - Y-axis: `total_bill`.
   - Boxes split by `smoker` status (different colors), showing median, quartiles, and outliers.
   - Useful to compare spending patterns by day and smoking status.

Visuals are displayed inline with matplotlib for each plot.

Assignment 5: Multi-Visual Comparison (Matplotlib) The Dataset: cities = ['Chennai', 'Mumbai', 'Delhi', 'Bangalore', 'Hyderabad'] sales_values = [450, 600, 520, 780, 410] categories = ['Electronics', 'Fashion', 'Groceries', 'Home Decor'] market_share = [35, 25, 30, 10] The Question: Create a single figure with two subplots (1 row, 2 columns): 1. Subplot 1 (Bar Chart): Plot `cities` vs `sales_values`. Set the bar color to 'teal', add a grid on the Y-axis, and label the axes. 2. Subplot 2 (Pie Chart): Plot the `market_share` for the four `categories`. Use the `explode` parameter to pop out the "Electronics" slice and show the percentage auto formatted to $1\%$. 3. Add a Main Suptitle to the entire figure: "Regional Sales & Category Analysis". 

Code:

import matplotlib.pyplot as plt

# Dataset
cities = ['Chennai', 'Mumbai', 'Delhi', 'Bangalore', 'Hyderabad']
sales_values = [450, 600, 520, 780, 410]
categories = ['Electronics', 'Fashion', 'Groceries', 'Home Decor']
market_share = [35, 25, 30, 10]

# Create figure and subplots
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# Subplot 1: Bar Chart
axes[0].bar(cities, sales_values, color='teal')
axes[0].set_xlabel("Cities")
axes[0].set_ylabel("Sales Values")
axes[0].set_title("City-wise Sales")
axes[0].grid(axis='y')

# Subplot 2: Pie Chart
explode = [0.1, 0, 0, 0]  # pop out Electronics
axes[1].pie(market_share, labels=categories, explode=explode, autopct='%1.0f%%', startangle=90)
axes[1].set_title("Market Share by Category")

# Main suptitle
fig.suptitle("Regional Sales & Category Analysis", fontsize=16)

plt.tight_layout(rect=[0, 0, 1, 0.95])
plt.show()

output:

Output Summary for Matplotlib Multi-Visual Figure:

1. **Subplot 1: Bar Chart (City-wise Sales)**
   - X-axis: Cities (`Chennai`, `Mumbai`, `Delhi`, `Bangalore`, `Hyderabad`)
   - Y-axis: Sales Values
   - Bars are colored **teal** with a **Y-axis grid**.
   - Shows Bangalore with the highest sales (780) and Hyderabad the lowest (410).

2. **Subplot 2: Pie Chart (Market Share by Category)**
   - Slices for `Electronics`, `Fashion`, `Groceries`, `Home Decor`.
   - **Electronics slice popped out** using `explode`.
   - Percentage labels displayed (rounded to nearest 1%).
   - Electronics has the largest share (35%).

3. **Figure Suptitle**
   - Main title: **"Regional Sales & Category Analysis"** appears centered above both subplots.

Visual result: Side-by-side comparison of city sales (bar) and category market share (pie).
